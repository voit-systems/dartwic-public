# Release 1.0.2
---

## Summary

DARTWIC Engine 1.0.2 fixes the development license bypass path for release builds.

## Notable Changes

- Development bypass licensing now short-circuits before signed-license sync, license file loading, or machine registration logic.
- Release builds now use the configured emergency license key consistently when generating the compiled license configuration.
- Startup config normalization remains supported; reordered `config.json` fields do not affect the bypass check.

## Migration Notes

- Replace the 1.0.1 engine package with the 1.0.2 engine package.
- Keep the development bypass key in `engine/config.json` under `license_key`.
- No `license.json` file is required for development bypass mode.
